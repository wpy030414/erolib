# PRD — EroLib 工口图书馆

> 产品需求文档。阐述功能存在的意义，让读者理解每个特性为何被纳入。

## 1. 产品定位

EroLib 是一款桌面端的**成人向漫画本地库**，覆盖「找图 → 下本 → 看本」完整工作流。它把浏览、下载、阅读、管理收进一个连贯的 Material Design 3 界面，所有数据留在用户自己的机器上。

**一句话**：浏览 → 下载 → 阅读，全程本地。

## 2. 为什么需要它

### 痛点

| 场景 | 现有方案 | 问题 |
|---|---|---|
| 发现新作品 | 浏览器手动浏览 Pixiv / EHentai / ASMHentai / NiceCat | 四个站点各自独立，无法统一浏览；频繁切标签 |
| 下载收藏 | 手动右键保存 / 浏览器扩展 / 命令行工具 | 操作碎片化，无法批量，无断点续传 |
| 本地阅读 | 看图软件 / ComicRack / CDisplayEx | 需要手动整理文件、缺少标签管理、不支持动图播放 |
| 跨设备阅读 | 网盘同步 / NAS | 需要额外搭建服务，配置复杂 |

### EroLib 的解法

把四个分散的流程收敛到一个桌面应用里：

1. **内置浏览器**：四个来源的 feed 统一展示在同一网格界面里，卡片三态（本地已有 / 下载中 / 未下载）让用户对每本作品的状态一目了然。
2. **统一任务管线**：所有下载走同一个 TaskManager 队列，带暂停/继续/取消/重试、步骤日志、实时下行速度，完成后自动入书库。
3. **沉浸式阅读器**：全屏阅读、键盘翻页、进度记忆、动图原生支持、自定义主题。
4. **OPDS / RSS 直出**：内置 HTTP 服务器把书库共享给局域网内任何阅读器（Panels、Chunky 等），无需额外搭建。

## 3. 功能需求

### 3.1 本地书库（Library）

**意义**：书库是核心——所有浏览下载的终点，所有阅读的起点。

- 导入 CB7 / CBZ / CBR / PDF，封面网格直观浏览
- 全文搜索匹配标题 / 作者 / 标签；标签 chip 行并集 (OR) 筛选，上限 30，满则折叠
- **阅读列表**：右键列表名直接内联重命名，重命名期间底部显示删除按钮，创建自动去重命名，上限 100 个
- 低清缩略图缓存到 IndexedDB，二次打开秒级加载
- 保留书源元信息（作者 · 发布日期 · 来源 URL），支持 ComicInfo.xml 无损导出 / 导入往返
- **本地单向同步**：把书库镜像到指定目录，`{标题}-{元信息哈希}.cb7`，已存在跳过，绝不删除目标文件

### 3.2 首页（Home）

**意义**：打开应用的第一个画面，给用户「我今天看了什么、花了多久」的即时反馈。

- Hero 区：**本周阅读时长**（按周一计，跨周一一致不重不漏）+ 库封面旋转展示墙（21 本）
- 「最近阅读」书架，点卡片直达阅读器
- 每本书右键菜单：加入列表 / 查看元信息 / 保存到本地 / 删除

### 3.3 沉浸式阅读器（Reader）

**意义**：漫画阅读是核心场景，体验必须流畅。

- 全窗口沉浸阅读，进出强制暗黑模式（退出自动恢复原模式）
- **贴合屏幕 / 贴合内容** 双缩放模式，进度滑块 + 键盘翻页 + 点击翻页
- 自动记忆每本书的阅读进度
- **动图 (ugoira) 原生支持**：保留原始 jpg 帧序列 + 逐帧延时，canvas 按时播放——不二次编码，转换瞬时、无损、原分辨率
- **右键菜单**：保存单页图片到本地、从当前页面提取自定义主题色
- **自动隐藏 UI**：bar zone 外启动 2s 计时隐藏
- 阅读时长增量上报：仅前台累计，防冻结灌秒

### 3.4 Pixiv 浏览式下载

**意义**：Pixiv 是插画/同人创作的主阵地，登录后能看到关注画师的新作和推荐。

- 登录后浏览式下载：**推荐 / 关注 / 收藏** 三大 feed + 关键词搜索
- IntersectionObserver 懒加载，无限滚动
- 卡片三态：本地已有 → 点进阅读；下载中 → 遮罩 + SVG 环形进度；未下载 → 红点提示
- 封面走后端代理，绕过 `i.pximg.net` 防盗链
- 动图 (ugoira) 完整下载与回放

### 3.5 EHentai / EXHentai 浏览式下载

**意义**：EHentai 是全球最大的同人志库，EXHentai 提供更稀有的内容。

- 登录后关键词搜索 + 10 大分类单选筛选
- **EXHentai 一键切换**（需 exhentai 资格）；未登录时自动隐藏搜索框与 EXHentai 开关
- 卡片三态同 Pixiv + 懒加载无限滚动

### 3.6 ASMHentai 浏览式下载

**意义**：公开站点无需登录，降低使用门槛。

- 无需登录，直接浏览与关键词搜索
- 卡片两态（已下载 → 阅读器；未下载 → 入队）
- 下载时自动抓取详情页补充元信息

### 3.7 NiceCat 浏览式下载

**意义**：中文漫画站，补全内容来源。

- 无需登录，无需内嵌浏览器
- 首页话题板块横向滚动 + 关键词搜索
- 卡片三态同 Pixiv / EHentai

### 3.8 任务系统

**意义**：下载是连接浏览与阅读的桥梁，必须可靠、可追踪。

- 所有下载统一经 TaskManager，无进程内回退
- 全部来源统一走 aria2 下载管线（8 并发），来源客户端仅抓取元数据
- 任务页左右分栏工作区：左侧任务卡片（运行中显示实时下行速度），右侧详情 pane（步骤日志、进度、创建/完成时间、操作区）
- 任务上限 100 条，完成后自动入书库，详情区一键跳转阅读器
- 支持暂停 / 继续 / 取消 / 重试，非侵入式 toast 通知
- aria2 自动检测系统 HTTP 代理，翻墙下载零配置

### 3.9 OPDS / RSS 共享服务器

**意义**：让用户在 iPad / 手机 / 其他设备上也能读到书库里的作品，无需额外搭建服务。

- 内置 OPDS 与 RSS 服务器，监听局域网
- **直出图片**：单页图 + HTML 画廊，RSS 阅读器可直接翻看整本图片序列
- **富摘要**：每条均带完整元信息
- feed 内链接使用本机局域网 IP，其它设备开箱即达
- ⚠️ 默认无鉴权，公共网络下建议手动关闭

### 3.10 主题与多语言

**意义**：个性化体验 + 国际化覆盖（主要用户群为中/英/日）。

- Material Design 3 动态主题：4 个内置种子色 + 自定义主题（从书页提取主色，上限 3 个）
- 中文 / English / 日本語三语界面，跟随系统或手动切换
- 标签数据库转译：1014 条种子词条，精确匹配优先 + 模糊匹配
- 五个主页面各自记忆当前 tab 与滚动位置

### 3.11 自动更新

**意义**：用户无需手动去 GitHub 下载新版本。

- 启动时静默检查 GitHub releases
- 下载走 aria2（复用代理检测），支持进度显示

## 4. 目标用户

- 成人向漫画/同人志爱好者
- 有本地化管理需求（不愿依赖云服务）
- 愿意在同一设备上浏览、下载、阅读

## 5. Goals / Non-Goals

### Goals

- 一站式覆盖「发现 → 下载 → 阅读 → 管理」全流程
- 全程本地，数据不离开用户机器
- 跨平台：macOS（Apple Silicon）+ Windows
- Material Design 3 高质量 UI
- 局域网内跨设备共享书库

### Non-Goals

- ❌ 云端同步 / 多设备数据同步
- ❌ 移动端（iOS / Android）原生应用
- ❌ 在线流式阅读（所有阅读都基于本地文件）
- ❌ 内容社区 / 评论 / 评分
- ❌ 付费内容 / 广告
- ❌ 非成人向漫画管理（功能兼容但不作为设计目标）
- ❌ Linux 平台原生支持
- ❌ 多用户 / 权限系统
- ❌ 图片编辑 / 裁剪 / 滤镜

## 6. 成功指标

| 指标 | 衡量方式 |
|---|---|
| 用户留存 | 周阅读时长 > 0（首页 Hero 区统计） |
| 下载成功率 | 任务 completed / (completed + failed) |
| 书库覆盖 | 导入 + 下载的书总量 |
| 共享使用率 | OPDS / RSS 服务器启用次数 |
